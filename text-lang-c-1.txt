Язык программирования C. Материал для урока №1 для моего сайта.

C — компилируемый, статически типизированный язык программирования в структурной парадигме.
Данный язык был создан еще в 70-х годах прошлого века как более высокоуровневая
    замена ассемблеру для более читаемого и быстрого в написании кода. В последствии,
    компиляторы C начали создавать код настолько большой оптимизации, что начали обгонять
    по скорости вручную написанный ассемблерный код даже самых лучших кодеров на ассемблере.

Сейчас этот язык считается низкоуровневым, так как сохраняет довольно много контроля над программой,
    взять ту же ружную работу с памятью. Используется этот язык в сфере десктопных и мобильных при-
    ложений, библиотек, так как ABI языка C поддерживается почти всеми современными популярными языками
    програмиирования, низкоуровневых и важных по своей легковесности программ, таких как операционные
    системы и emmbeded разработки (т.е. работы с кодом и прошивками для микроконтроллеров и т.п.).
Также, C активно используется в образовательных целях, так как это один из самых простых и минималис-
    тичных языков программирования.

Для начала работы с C нужно установить компилятор этого языка. Из самых популярных — GCC, Clang и MSVC.
    Они практически ничем не отличаются, только их расширения и скорость работы финальной скомпилированной
    программы будут немного отличаться. Для ОС Windows (у меня именно такая), я использую компилятор GCC
    в составе пакета MinGW-w64, который является портом GCC (изначально созданного для Unix-подобных систем)
    для Windows. Хотя, все же каноничнее для Windows использовать именно компилятор от самой Microsoft —
    MSVC (Microsoft Visual C). Гайдов по скачиванию любого компилятора на просторах интернета много, так
    что с этим вы можете разобраться сами.
